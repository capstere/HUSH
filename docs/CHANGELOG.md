# 3.0.0 — hands-on edition

Replaces the 2.0 move-selection/minigame dock with direct manipulation of a jointed arm and leg. Gentle contacts reduce snoring; fast contacts do more but raise risk. One contact per gesture. A clearly signaled stirring window makes immediate repeat contact dangerous.

Adds a physical headphone stand, wearable headphones, local nonsense-audiobook synthesis, fast battery depletion, visible charging and automatic return when empty. Adds a hands-on, untimed first-play lesson, optional tap mode, safe shushing with a breath limit, and a simple duvet comfort move.

Rebuilds the seven-event system around scene interactions: fart/fanning, nightmare/three monsters, bathroom/green-red floorboards, phone/tap, cat/drag to rug, duvet/tug and mosquito/tap. No overlapping timed events. A cat successfully moved to the rug remains there.

Adds articulated finger-following motion, spring return, responsive duvet, breathing and blinking, a partially opened eye while stirring, headphone movement, dawn tint, event animation and local sound effects. Retains the English language, top-down blue-bed concept and original base snore/foley bank.

Includes mobile safe areas, single-pointer capture/cancellation, auto-pause, volume/mute, reduced motion, next-night difficulty and local records. Storage is versioned under `hush.v3`; the previous `hush.v2` data is not destroyed or overwritten.

No changes to `capstere/sw`. Previous 2.0 source remains recoverable in this repository's Git history at commit `13bf0df5c7e93f32db7810d865033a81a8c5de1c`.
